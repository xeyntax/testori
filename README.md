# Ayam Gepuk Ori Selayang

Buildless website using HTML, CSS and JavaScript. Open `index.html` in your browser, or upload this folder to any static web host. No dependencies or build step.

## Updating content
- `index.html`: page copy, footer and contact layout.
- `style.css`: palette, responsive layout and original CSS/SVG delivery rider animation.
- `app.js`: outlets, menu descriptions, job roles, navigation and inquiry receipt.
- `assets/`: supplied images, preserved in their original formats.
